# :app (Android application)

## Responsibility

- Android application module and runtime entrypoint.
- Aggregates feature/library/service implementations.
- Hosts the single Activity and sets up root DI graph.

## Entrypoints

- Manifest: `app/src/main/AndroidManifest.xml`
- Application: `app/src/main/kotlin/io/element/android/x/ElementXApplication.kt`
- Activity: `app/src/main/kotlin/io/element/android/x/MainActivity.kt`

## DI

- App graph: `app/src/main/kotlin/io/element/android/x/di/AppGraph.kt` (`@DependencyGraph(AppScope::class)`)
- App bindings surface: `app/src/main/kotlin/io/element/android/x/di/AppBindings.kt`

## Navigation

- NodeHost is created from `MainActivity`.
- The initial node resolves into `:appnav` root flow.

## Build/Run

- Variant dimensions: `store` (`fdroid` default, `gplay`) + additional Schildi-specific flavor dimensions.
- Versioning and applicationId are overridden for Schildi builds in `app/build.gradle.kts`.
