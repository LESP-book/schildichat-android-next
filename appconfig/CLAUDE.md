# :appconfig (BuildConfig-backed app config)

## Responsibility

- Provides build-time configuration (BuildConfig fields) consumed by runtime modules.

## Key Files

- Gradle config: `appconfig/build.gradle.kts`
- BuildConfig fields: `appconfig/build.gradle.kts` (e.g. `URL_POLICY`, `BUG_REPORT_URL`)
